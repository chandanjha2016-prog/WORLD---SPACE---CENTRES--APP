# WORLD SPACE CENTRE APP 🚀🌌

**The Open Source Hub for Space Education, Research & Exploration**

A 100% Free, Offline-First Web Platform for Students, Researchers and Space Enthusiasts.

### Key Features
- **3D Interactive Solar System** with real-time data
- **Global Mission Database**: ISRO, NASA, ESA, SpaceX - Past, Present, Future
- **Scientist Archive**: 500+ Biographies, Inventions, Research Years
- **Space Travel Simulator**: Earth to ISS, Moon, Mars
- **Satellite & Debris Tracker**: Why satellites burn in atmosphere
- **Research Library**: Summarized papers from ISRO/NASA
- **Pro Tools**: Orbit Calculator, Launch Simulator, AR View
- **Exam Prep**: UPSC, ISRO, GATE, NASA quiz bank
- **Offline + Multi-language + No Login**

### Tech Stack
HTML5, CSS3, Vanilla JS, Three.js for 3D, JSON Database
